# Guewen Heslan — personal academic website

Static bilingual site (English at the root, French under `/fr/`), served by GitHub Pages at
<https://gheslan.github.io>. No framework: plain HTML/CSS/JS generated by a small Python script.

## Updating the content

All text and data live in `content/` (TOML files, easy to edit):

| File | What it contains |
|---|---|
| `content/site.toml` | name, emails, academic profile links (ORCID, Scholar, RePEc…), home page text, news, statistics code |
| `content/research.toml` | working papers, work in progress, conferences, map locations |
| `content/cv.toml` | education, teaching, employment, awards, skills |
| `content/teaching.toml` | current courses (one page each), course materials, previous courses |

Then rebuild the pages and publish:

```bash
python src/build.py
git add -A
git commit -m "Update content"
git push
```

Requires Python 3.11+ (standard library only).

### Adding course materials

Put the file in `files/teaching/<course>/` and declare it in `content/teaching.toml`
(see `files/teaching/README.md`). It then appears on the course page.

### Adding a conference

Add a `[[talks]]` entry in `content/research.toml`. If the city is new, also add it under
`[locations]` (latitude/longitude): it will appear on the conference map automatically.

## Project structure

```
content/              Editable content (TOML)
src/build.py          Page generator            → *.html, fr/*.html, teaching/, sitemap.xml, robots.txt
src/figures.py        Animated figures of the working papers
src/basemap.py        Rebuilds the map outline (only if the map window changes)
src/og_image.py       Rebuilds the link-preview image assets/img/og-image.png (needs Chrome)
assets/               CSS, JS, images, logos
files/teaching/       Course materials (PDFs…)
```

Generated HTML files are committed so that GitHub Pages can serve them directly.

## Optional: visitor statistics

The site can use [GoatCounter](https://www.goatcounter.com): free for personal sites, no cookies,
no personal data stored, so no consent banner is required. Create an account, then set
`goatcounter = "<your code>"` in `content/site.toml` and rebuild.

## Optional: Google Search Console

To follow how the site appears in Google, add the property `https://gheslan.github.io/` in
[Search Console](https://search.google.com/search-console) (HTML-tag verification: send me the
`<meta name="google-site-verification">` tag to add), then submit `https://gheslan.github.io/sitemap.xml`.

## Private files

`docs/` (source CV with a phone number) and `docs_not_in_the_site/` (unsubmitted papers) are
excluded by `.gitignore` and never published.

## Preview locally

```bash
python -m http.server 8000
```
then open <http://localhost:8000>.
